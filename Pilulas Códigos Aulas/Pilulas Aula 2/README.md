📚 Exercícios de Python — Pílulas de Conhecimento

Este repositório reúne alguns dos exercícios desenvolvidos durante as aulas de Python, com o objetivo de praticar conceitos básicos de programação e o uso de diferentes bibliotecas da linguagem.

As atividades foram feitas utilizando situações práticas, como controle de receitas, análise de produção, cálculo de garantia, simulação de cotação do dólar e projeção de assinantes e receitas.

🎯 Objetivo

O objetivo dos exercícios é desenvolver a lógica de programação e aprender a utilizar recursos da linguagem Python para realizar cálculos, receber dados do usuário, trabalhar com datas, gerar valores aleatórios e fazer projeções.

🐍 Conteúdos praticados Entrada de dados utilizando input() Conversão de valores com int() e float() Operações matemáticas Formatação de números com f-strings Formatação de valores monetários Cálculo de média e desvio padrão Manipulação de datas Geração de números aleatórios Projeções matemáticas Utilização de bibliotecas do Python 📌 Exercícios 💰 1. Cálculo de receitas

Neste exercício, são informadas as receitas de três meses. O programa calcula e apresenta cada valor e também o total das receitas.

Foi utilizada a biblioteca locale para trabalhar com a formatação de valores monetários.

📊 2. Análise de produção

O programa recebe a quantidade produzida em três lotes e calcula:

Média da produção; Desvio padrão dos valores.

Para isso, foi utilizada a biblioteca statistics.

📅 3. Prazo de garantia

Neste exercício, o usuário informa a data de uma compra e o prazo da garantia em meses.

A partir dessas informações, o programa calcula a data final da garantia e informa também o dia da semana correspondente.

Foi utilizada a biblioteca datetime.

💵 4. Simulação da cotação do dólar

O programa recebe a cotação atual do dólar e simula uma variação aleatória entre -1,5% e +1,5%.

Depois, é calculada uma nova cotação com base nessa variação.

Foi utilizada a biblioteca random.

📈 5. Projeção de assinantes e receita

Neste exercício, são informados:

Número atual de assinantes; Valor da mensalidade; Taxa de crescimento mensal; Quantidade de meses para projeção.

Com esses dados, o programa estima a quantidade de assinantes e a receita mensal ao final do período.

Foi utilizada a biblioteca math para realizar a projeção.

🛠️ Tecnologias utilizadas Python 3 locale statistics datetime random math 📖 Aprendizados

Com esses exercícios, pude praticar conceitos importantes da programação em Python e entender como diferentes bibliotecas podem ser utilizadas para resolver problemas do dia a dia.

As atividades também ajudaram a desenvolver a lógica de programação, trabalhar com entrada e saída de dados e aplicar fórmulas e cálculos em situações práticas.
