Exercícios de Python
Repositório criado para armazenar exercícios e práticas desenvolvidas durante os estudos de Python.

Os exercícios têm como objetivo praticar conceitos fundamentais da linguagem, principalmente funções, estruturas condicionais, loops, entrada de dados e cálculos.

📚 Exercícios
1. Calculadora de Soma e Média
Programa que apresenta um menu com três opções:

1 - Soma: recebe dois números e calcula a soma.
2 - Média: recebe dois números e calcula a média.
3 - Sair: encerra o programa.
Também possui uma opção para informar uma escolha inválida.

2. Verificação de Número Primo
Função ehPrimo(n) responsável por verificar se um número é primo.

O programa testa os números divisíveis entre 2 e n - 1. Caso encontre um divisor, o número não é primo.

3. Contagem de Notas
Função contarNotas(valor) que calcula a quantidade de notas necessárias para representar determinado valor.

São utilizadas notas de:

R$ 100
R$ 50
R$ 20
R$ 10
O exercício utiliza operações como divisão inteira (//) e resto da divisão (%).

4. Cálculo de Média com Recuperação
Função calcularNotas() que recebe três notas, calcula a média e verifica a situação do aluno.

Caso a média seja menor que 6, é solicitada uma nota de recuperação. A nova média é calculada utilizando a média anterior e a nota da recuperação.

Ao final, o programa informa se o aluno foi:

Aprovado
Reprovado
5. Verificação de Valores Crescentes
Função verificarValores() que recebe cinco leituras e verifica se os valores estão sempre aumentando.

Caso cada valor seja maior que o anterior, o programa informa:

crescente

Caso contrário:

instável

Esse exercício trabalha principalmente com loops, comparação de valores e variáveis de controle.

6. Simulação de Crescimento Populacional
Função simularCrescimento(pop, taxa, limite) utilizada para calcular quantos anos são necessários para uma população atingir ou ultrapassar determinado limite.

O programa recebe:

População inicial
Taxa de crescimento em porcentagem
Limite desejado
A população é atualizada ano após ano até ultrapassar o limite.

🧠 Conceitos praticados
Durante os exercícios foram trabalhados conceitos básicos e importantes de Python:

Variáveis
Entrada de dados com input()
Conversão de tipos com int() e float()
Operações matemáticas
Estruturas condicionais if, elif e else
Estruturas de repetição for e while
Funções com def
Parâmetros e argumentos
Retorno de valores com return
Operadores relacionais
